# VFX AI MINI

Neon mobile-friendly WhatsApp pairing portal deployed on Vercel. The portal forwards pairing requests to a separately hosted, persistent Node.js/Baileys backend.

## Vercel setup

1. Import this repository into Vercel and deploy the `main` branch.
2. In Vercel → Project → Settings → Environment Variables, add:
   - `BOT_API_URL` = your Render backend base URL, e.g. `https://your-bot-service.onrender.com` (no trailing slash).
3. Redeploy after setting the variable.
4. Open `/api/health` to verify the backend connection.

## Render backend requirements

The backend must run the Baileys WhatsApp socket as a persistent Node.js web service, expose `/health` and `/pair?number=...`, and keep its session/auth files on a persistent Render disk. Vercel cannot keep the WhatsApp socket alive or persist Baileys session files.

Use the actual backend service URL in `BOT_API_URL`. Do not put WhatsApp session credentials or API secrets in frontend code.

## Troubleshooting

- `Website online · Set BOT_API_URL...`: the Vercel environment variable is missing.
- `Bot backend is not reachable`: check the Render service status, logs, URL, and that the backend exposes `/health`.
- Pairing fails after backend connection: check Render logs; pairing codes are generated by the backend, not Vercel.
